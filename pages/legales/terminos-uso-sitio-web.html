Términos de uso del sitio web

Reglas para navegar, utilizar formularios y consultar información sin afectar la seguridad ni los derechos de terceros.

1. Uso permitido

El sitio puede utilizarse para informarse, comparar experiencias, solicitar cotizaciones, registrar pasajeros, consultar documentos y comunicarse con My Cusco Trip. No se permite interferir con su funcionamiento, automatizar consultas abusivas, intentar acceder a cuentas ajenas, extraer bases de datos ni usar el contenido para fraude o suplantación.

2. Información del sitio

Trabajamos para mantener el contenido actualizado, pero horarios, disponibilidad, precios, circuitos, requisitos y condiciones de proveedores pueden cambiar. La confirmación individual enviada al viajero prevalece sobre información general del sitio.

3. Cuentas, códigos y enlaces de acceso

Los códigos de reserva, correos, contraseñas y enlaces de verificación son personales. El usuario debe mantenerlos bajo control y comunicar cualquier uso no autorizado. Las consultas de vouchers y tickets requieren coincidencia entre código y correo registrado.

4. Propiedad intelectual

La marca, diseño, textos originales, estructura, fotografías propias, ilustraciones y código del sitio están protegidos. Los logos y contenidos de terceros pertenecen a sus respectivos titulares y se utilizan con fines informativos o bajo autorización cuando corresponda.

5. Enlaces externos

El sitio puede enlazar a plataformas oficiales, pasarelas de pago o proveedores. My Cusco Trip no controla sus políticas, disponibilidad o seguridad. Verifica siempre el dominio antes de ingresar datos o realizar pagos.

6. Disponibilidad y seguridad

Podemos suspender temporalmente funciones por mantenimiento, seguridad o causas técnicas. No se garantiza disponibilidad ininterrumpida, pero se aplican medidas razonables para reducir errores y proteger la información.

7. Contacto

Reporta errores, enlaces sospechosos o problemas de acceso a contact@mycuscotrip.com.
