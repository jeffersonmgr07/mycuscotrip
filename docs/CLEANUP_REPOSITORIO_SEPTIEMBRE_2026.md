## No eliminar en esta fase

- `backend/`: código fuente de Apps Script/agencias; que no se importe desde HTML no significa que esté inactivo, porque Apps Script se despliega fuera de GitHub Pages.
- `google-apps-script/`: backend principal Apps Script.
- `google-apps-script-hoteles.gs`: backend de hoteles.
- `trenes/backend/`: Apps Script y plantilla del módulo de trenes.
- `agencias/*.gs`: hay variantes/versiones; borrar solo tras comparar con el deployment real.
- `assets/data/`: conserva datos del cotizador/operación aunque la capa comercial pública sobrescriba ciertos precios.

## Estructura recomendada

Deja solo `README.md` como documentación principal en la raíz. Mantén documentación viva en `docs/` y bitácoras históricas en `docs/archive/`. No conviene unir todos los `.md`: arquitectura, contratos, procedimientos y especificaciones tienen propósitos distintos.
